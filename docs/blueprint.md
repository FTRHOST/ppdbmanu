# **App Name**: MANSABA PPDB

## Core Features:

- Form Pendaftaran: Formulir pendaftaran peserta didik baru dengan validasi data dan penyimpanan otomatis ke database. Mencakup data peserta didik, data alamat, data orang tua/wali, dan data sekolah asal.
- Halaman Admin: Halaman admin untuk mengelola data pendaftar, data daftar ulang, laporan, petugas pendaftaran, dan pengaturan PPDB. Fitur termasuk input daftar ulang, tampilan data pendaftar, laporan harian, dan pengaturan tahun pelajaran/gelombang.
- Otomatisasi Nomor: Otomatisasi pembuatan nomor pendaftaran dan nomor daftar ulang.

## Style Guidelines:

- Dominant color: Shades of green for a fresh and natural feel, reflecting the school's identity.
- Secondary color: Light gray or beige for backgrounds to provide contrast and readability.
- Accent: A shade of gold (#FFD700) to highlight important elements and calls to action.
- Clear and readable typography for form fields and data tables.
- Simple and intuitive icons to represent different sections and actions.
- Responsive layout adapting to different screen sizes for optimal viewing on all devices.
- Subtle animations for transitions and feedback to enhance user experience.
